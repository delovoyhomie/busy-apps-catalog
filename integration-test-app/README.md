# TEST Discord Forum Sync

A temporary app fixture for testing automatic GitHub PR posts in the BUSY Discord forum.
This is not a contest entry or a request to publish an app. Do not merge the test PR.

The front display shows `SYNC TEST`. Press Back to quit. The app uses no network services,
saves no data, and has no background timer.

Build and run with the official BUSY Bar Emulator. The screenshots in this folder are
native 72x16 captures from that emulator, with an enlarged copy for inspection.
